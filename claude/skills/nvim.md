## Key Configuration Details

### Editor Options (`lua/config/options.lua`)
- **Indent**: 4 spaces (shiftwidth, tabstop, softtabstop all = 4)
- **expandtab**: true
- **cmdheight**: 0 (command line hidden until used)

### Adding Plugins
Always add to `lua/plugins/` as a new file returning a spec table:
```lua
return {
  "author/plugin-name",
  event = "VeryLazy",   -- or BufReadPost, VimEnter, etc.
  config = function()
    require("plugin-name").setup({ ... })
  end,
}
```

### Updating LazyVim Extras
Extras are managed in `lazyvim.json`. To override a LazyVim default plugin, return a spec with `enabled = false`:
```lua
-- In lua/plugins/theme.lua (example pattern used here)
return {
  { "LazyVim/LazyVim", opts = { colorscheme = "mellow" } },
  { "rebelot/kanagawa.nvim", enabled = false },  -- disable LazyVim default
}
```

## Keybindings Reference

### Window / Pane Navigation
All navigation is unified across Neovim splits and Tmux panes via `vim-tmux-navigator`:
- `<C-h>` — left
- `<C-j>` — down
- `<C-k>` — up
- `<C-l>` — right
- `<C-\>` — previous pane

### Motion (Flash)
- `s` — jump to any location (normal/visual/operator)
- `S` — treesitter-aware jump
- `r` — remote flash (operator pending)
- `R` — treesitter search (operator/visual)
- Incremental search: **disabled**
- Label chars: `asdfghjklqwertyuiopzxcvbnm`

### Telescope
- `<leader>f/` — grep in a prompted directory (custom)
- Standard LazyVim telescope bindings otherwise apply

### Org-Roam (`<leader>r` group)
- `<leader>ra` — Org agenda prompt
- `<leader>rd` — Open today's daily note
- `<leader>rf` — Find node
- `<leader>ri` — Insert node link
- `<leader>rb` — Toggle backlinks buffer
- `<leader>rs` — Search headings (telescope-orgmode)
- `<leader>rr` — Refile heading
- `<leader>rl` — Insert link
- `<leader>rt` — Search by tag

### Dashboard Shortcuts (startup screen)
- `d` — today's daily note
- `f` — find files
- `g` — live grep
- `r` — recent files
- `e` — file explorer (Neotree)
- `c` — edit config
- `l` — Lazy plugin manager
- `q` — quit

## Org-Roam Setup

### Notes Directory
```
~/notes/roam/
├── daily/          # YYYY-MM-DD.org — auto-created on VimEnter
├── permanent/      # Permanent notes
└── meetings/       # Meeting notes
```

### Daily Note Structure
Generated by `lua/config/org_roam.lua` (`ensure_daily_note`):
```org
:PROPERTIES:
:ID:       <uuid>
:END:
#+title: <Weekday, Month DD, YYYY>
#+filetags: :daily:
#+date: YYYY-MM-DD

* Tasks
** TODO <cursor>

* Thoughts

* Connections

* Reflection
```

Key functions in `lua/config/org_roam.lua`:
- `M.ensure_daily_note(date)` — creates note if missing
- `M.open_today_daily_note()` — opens today's note
- `M.daily_note_templates(date)` — returns template spec

### On-Save Sync
Every `.org` file save triggers:
1. org-roam DB reload (Neovim side)
2. `emacsclient` call to sync `org-roam-ui` graph in Emacs

## Troubleshooting

### Plugin Not Loading
```vim
:Lazy                   " Check plugin status
:LazyHealth             " Diagnose issues
:checkhealth            " Full health check
```

### Keybinding Not Working
```vim
:WhichKey <leader>      " See all leader bindings
:verbose map <key>      " Check what's bound and where
```

### Config Error on Startup
- Read the error message — it includes file + line number
- Lua errors from `lua/plugins/` won't prevent other plugins loading (lazy.nvim isolates them)
- Check with `:Lazy` if a specific plugin failed

### Org-Roam DB Issues
```vim
:lua require("org-roam").database:load({ force = true }):wait()
```
Or delete `~/.local/share/nvim/org-roam.db` and restart.

## Common Patterns

### Adding a Keymap
```lua
-- In lua/config/keymaps.lua or lua/plugins/yourplugin.lua
vim.keymap.set("n", "<leader>x", function()
  -- action
end, { desc = "Description shown in which-key" })
```

### Overriding a LazyVim Plugin's Options
```lua
return {
  "nvim-telescope/telescope.nvim",
  opts = {
    defaults = {
      -- your overrides merge with LazyVim defaults
    },
  },
}
```

### Adding an Autocmd
```lua
-- In lua/config/autocmds.lua
vim.api.nvim_create_autocmd("FileType", {
  pattern = "lua",
  callback = function()
    -- runs when a lua file opens
  end,
})
```

## Integration Notes

- **Tmux**: vim-tmux-navigator handles all pane/split navigation — don't remap `<C-h/j/k/l>` without updating both nvim and tmux configs
- **Emacs**: org-roam-ui runs in Emacs; Neovim syncs to it via `emacsclient` on `.org` save. If emacsclient isn't running, the sync silently fails (detached job)
- **Comments**: Custom dark gray italic comment highlight is set in `lua/config/autocmds.lua` via `ColorScheme` autocmd — reapplied on theme change
- **Dashboard TODOs**: Pulled from org agenda files (`~/notes/roam/**/*.org`) at startup; sorted by priority [#A] > [#B] > [#C], then file mtime
